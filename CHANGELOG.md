# Changelog

## 1.0.0 — 2026-09-19

Initial Dentiva production foundation:

- Premium light-only desktop shell and responsive design system.
- Empty first-run clinic setup wizard with local administrator password hashing.
- Dashboard focused on clinical operations, appointment flow, queue, follow-up, and recent activity.
- Patient directory, private patient profile, clinical visit timeline, configurable patient IDs.
- Appointments, today queue, walk-in workflow, status progression, and search.
- Treatments, prescriptions, referrals, document metadata, invoices, payments, expenses, staff, reports, settings, audit log, and About page.
- English default and runtime Bengali navigation localization.
- Native desktop persistence boundary, backup/restore dialogs, print hand-off, and privacy-safe renderer bridge.
- Multi-resolution Dentiva icon assets and Electron Builder Windows installer/portable configuration.
- Automated safety-oriented tests and manual QA documentation.
